# Система синхронизации данных университета

## Описание проекта

Информационная система для управления распределенными данными университета с трехуровневой иерархической структурой: **Ректорат → Факультет → Кафедра**.

Система обеспечивает:
- Синхронизацию данных между уровнями иерархии
- Автоматическое разрешение конфликтов через приоритеты
- Каскадное распространение удалений
- Разграничение прав доступа по уровням

---

## Архитектура системы

### Трехуровневая структура

### Механизм синхронизации

- **SyncDown** (вниз): структура, студенты, приказы
- **SyncUp** (вверх): студенты, оценки
- **Инкрементальная синхронизация**: передаются только изменения с `updated_at >= lastSync`
- **Приоритеты**: `source_level` ( 2=Факультет, 3=Кафедра)

## Установка и настройка

### Шаг 1. Установка PostgreSQL

1. Скачайте PostgreSQL с официального сайта: https://www.postgresql.org/download/
2. Установите PostgreSQL, запомните пароль пользователя `postgres`

### Шаг 2. Создание баз данных

**ВАЖНО: Создайте три отдельные базы данных!**

Откройте pgAdmin или psql и выполните:

```sql
-- База данных Ректората
CREATE DATABASE university_db;

-- База данных Факультета ИТ
CREATE DATABASE faculty_it_db;

-- База данных Кафедры ПО
CREATE DATABASE dept_po_db;
